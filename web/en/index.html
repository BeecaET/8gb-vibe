8GB Vibe started on a MacBook Air M2 with 8 GB of RAM. It ran many Claude Code sessions, Xcode, Gradle and Docker at once. One morning it barely responded to a click.

Freeing about 17 GB of disk did not help. The estimated memory demand of everything open was about 15-16 GB on an 8 GB Mac. When measured again, macOS was relying heavily on compressed memory and swap. There were 16 Claude Code sessions at about 200-300 MB each; 14 had been open for 22-42 hours with little CPU use. This is one Mac under a heavy workload, not a typical load for every 8 GB Mac.

Agents check the Mac before heavy jobs

  1. machine_status

    can_start

    Ask first

    MCP is how an AI client calls 8GB Vibe’s tools. Once configured, an agent that chooses to call them can read RAM, swap and the heavy jobs already running, and get advice before a big build or test run.

  2. acquire_slot

    renew_slot

    one heavy-job turn, with a time limit

    Ask for a turn

    The agent registers and asks for a turn before a heavy job. This helps participating agents avoid running on top of each other; it cannot stop agents or tasks that skip the turn.

  3. release_slot

    post_message

    hand the turn back when done, leave a note for other agents

    Hand back the turn

    When the job is done, the agent hands the turn to the next one. A long job needs to renew its turn. Holding a turn does not guarantee enough RAM; the MCP tools only read state and coordinate, and never stop processes or clean up data.

Go to Settings → AI Agents to add the MCP server to the clients found on your Mac. The app asks for confirmation, then uses the client’s own command or edits its config directly. Existing files it edits directly are backed up, and you can remove the connection later. You may need to restart the client. Or run this command for Claude Code if 8GB Vibe is in /Applications:

claude mcp add --transport stdio --scope user 8gbvibe -- "/Applications/8GB Vibe.app/Contents/Helpers/8gbvibe-mcp"

FAQ

Is 8GB Vibe really free?

Yes. It is 100% free, with no ads, no paid tier and no account.

Does the app collect my data?

The app reads and processes data on your Mac and keeps its log and measurements locally. It makes no Internet connections of its own and sends no data to BEECA. To group processes, it reads the names and command-line arguments of some processes, on your Mac only. The MCP server uses stdio and opens no network port. When you connect MCP, the AI client can receive the Mac’s state and project names; whether that client sends data to its AI provider depends on its own settings and policy.

Does the app or the MCP server close anything on its own?

The app makes suggestions for you to review and always asks for confirmation before closing an app or stopping a process. The MCP tools only read state and coordinate. The app will not stop a Claude Code session directly; closing the Terminal or app that holds it can still interrupt the work inside.

How accurate are the numbers?

RAM, swap, CPU and disk figures are read from macOS at intervals; not every process can be read. The RAM budget, room for a new session and the RAM of an item you plan to close are estimates. After closing, the app measures RAM and swap again; the result can include other activity. Low CPU activity does not mean a session is finished.

What is swap?

Swap is space on the disk that macOS uses to move data out of RAM. Heavy swap reads and writes can slow the Mac down; a large swap size on its own does not prove the Mac is short on RAM. 8GB Vibe helps you watch this and choose what to ease off; it does not add physical RAM.

My Mac has 16 GB. Do I need it?

The app is aimed at Macs with little RAM and works on 16 GB and up. It picks thresholds for your configuration; the 16 GB and 24 GB-plus profiles are still experimental. A lot of swap in use is not enough to conclude RAM is short: also look at memory pressure and swap read/write rates.

Does it run on Intel Macs?

Yes. The download is universal and runs on Apple silicon and Intel, on macOS 13 or later. The interface is in English and Vietnamese.

I can’t see the menu bar icon.

First, open 8GB Vibe from Applications. If the menu bar is full or the notch covers the icon, remove items you do not need to make room. On macOS versions with System Settings → Menu Bar, check that 8GB Vibe is allowed to show. Not every macOS version has this setting.

How do I update or uninstall it?

To update, download the new DMG here, quit the old app, drag the new one to Applications and choose Replace. To uninstall, quit the app and delete 8GB Vibe from Applications; its log and local data remain in ~/Library/Application Support/8GB Vibe. If you installed the MCP server, remove it first in Settings, AI Agents tab.
